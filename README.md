# skills

Personal [Claude Code](https://claude.com/claude-code) skills.

| Skill | Description |
|---|---|
| [statusline](statusline/) | Compact, width-aware status line: model, context bar, 5h/7d usage with pace prediction, git, PR/CI, cost, sessions |

## Install a skill

```bash
git clone https://github.com/aditnole/skills.git ~/aditnole-skills
ln -s ~/aditnole-skills/statusline ~/.claude/skills/statusline
```

Then ask Claude Code to "set up my status line" (or run `/statusline`).
